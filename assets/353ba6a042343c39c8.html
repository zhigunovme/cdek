Личный кабинет

В Личном кабинете Вы можете:

  • отследить заказы
  • самостоятельно оформить и распечатать заполненные для отправки накладные
  • произвести расчет стоимости доставки с учетом предоставленных скидок по одному или нескольким направлениям
  • получить информацию о состоянии счета
  • получить информацию о контактах закрепленных сотрудников
  • получить акты оказанных услуг за весь период
  • сформировать акт сверки
  • получить информацию по реестрам перечисления наложенных платежей
  • произвести аналитику на выкупаемость заказов для интернет-магазинов

Авторизация

Для начала работы необходимо перейти в ЛК по ссылке https://lk.cdek.ru/

Для авторизации в системе введите свой логин и пароль и нажмите на кнопку Войти.

После авторизации Вы автоматически попадаете в раздел «Мои заказы»:

Язык интерфейса. Выбирается при помощи выпадающего списка ( по умолчанию — русский ):

Новости. Данный раздел предназначен для получения пользователем текстовых оповещений:

Раздел «Новости» состоит из 4 вкладок:

  • Важно — информация о важных изменениях в компании и изменениях связанных с заказами клиентов
  • Новые офисы — информация об открытии новых ПВЗ
  • Новые услуги — инфомрация о появлении новых услуг
  • Прочие новости — оповещения, не попадающие ни в одну из перечисленных категорий

Мои задачи. В данном разделе отображается информация об операциях, совершённых пользователем:

  • Дата создания
  • Название задачи
  • Результат

С помощью кнопки Все задачи, Вы можете перейти в раздел «Мои задачи» для просмотра более подробной информации.
