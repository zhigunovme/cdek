Новый заказ

Для оформления заказа необходимо заполнить:

  • Расчет стоимости заказа — позволяет произвести расчет стоимости заказа исходя из характеристик отправляемого груза
  • Отправитель — указываются контактные данные отправителя
  • Получатель — указываются контактные данные получателя
  • Список товаров — указывается список товаров для доставки. Раздел доступен только для типа доставки «интернет-магазин»
  • Подтверждение — показывает всю введенную информацию по заказу, перед сохранением его в системе

Внимание: заказ производится в двух режимах: «Доставка» и «Интернет-магазин». Для доставки шаг «Список товаров» отсутствует

Расчет стоимости заказа

Примечание: формировние заказа для юр.лица и физ.лица может отличаться

Заполните следующие поля:

  1. Тип доставки — доставка/интернет-магазин
  2. Вы являетесь — выберите один из вариантов, который описывает Ваше отношение к грузу: отправитель, получатель, третье лицо
  3. Откуда — введите название населенного пункта, откуда будет отправлен груз
  4. Куда — введите название населенного пункта, куда прибудет груз
  5. Параметры мест — укажите параметры доставляемого груза
    • Вес — укажите вес отправляемого груза в кг
    • Габариты — укажите длину, высоту и ширину отправляемого груза в см
    • Описание груза — укажите описание груза (например: одежда, книги и т.д.)
    • Нажмите на ссылку , если груз состоит из нескольких мест и введите информацию о весе, габаритах дополнительного места. Для ввода нескольких однотипных мест воспользуйтесь кнопкой  в поле «Описание груза»
  6. Условия оплаты — укажите как будет происходить оплата доставки (при выборе типа доставки «интернет-магазин» данный шаг будет недоступен, т.к. расчет будет происходить только по договору)

Нажмите на кнопку , чтобы перейти к списку тарифов и заполните открывшиеся поля:

  1. Список тарифов — выберите один из тарифов для отправки
  2. Доп. услуги — раздел содержит список дополнительных услуг, которые могут быть добавлены к тарифному плану
  3. Для интернет-магазина услуга «страхование» является обязательной, поэтому укажите «Объявленную стоимость товара»После заполнения этих полей Вы увидите итоговую сумму стоимости отправления и детали расчета.Внимание: при расчете стоимости доставки учитываются не только весовые, но и габаритные характеристики. Таким образом, доставка легкого, но объемного груза обойдется дороже, чем предмета с тем же весом, но малого объема. Включаются также дополнительные сборы за превышение габаритов или особенности груза:
    • Негабаритный груз — если длина, ширина или высота превышает 150 см
    • Опасный груз — груз, который может повредить другие грузы (например, жидкости). Для категории опасный груз может быть также изменен и срок доставки
    • Тяжелый груз — груз весом более 75 кг
    Вы можете нажать кнопку  и остановить формирование заказа, при этом сохранив заполненные поля, чтобы вернуться к оформлению позже.Или продолжить оформление заказа и перейти к заполнению следующих полей.

Отправитель

В блоке «Отправитель» указывается время визита курьера и контактные данные отправителя.

Примечание: если адресная книга работает в автоматическом режиме, то после заполнения полей информация о контакте попадет в адресную книгу, когда Вы перейдете на следующий шаг. Если адресная книга работает в режиме «Вручную» — после заполнения полей в разделе появится кнопка Добавить контакт для сохранения в адресной книге. После нажатия на кнопку появится сообщение «Контакт успешно добавлен», а сам контакт сохранится в адресной книге

Если отправитель уже есть в адресной книге, то при заполнении поля инициалов будет выведена строка для подстановки.

После заполнения полей «Отправитель» переходим к заполнению полей «Получатель».

Получатель

В разделе указывается получатель и контактные данные для связи с ним. Если получатель уже есть в адресной книге, то при заполнении поля инициалов будет выведена строка для подстановки.

Если Вы выбрали режим доставки «до склада», то в разделе «Получатель» отобразятся: карта и список офисов. Вы можете просматривать ПВЗ только выбранного города или в радиусе 100 км, для переключения режима нажмите в правом верхнем углу карты кнопку с соответствующим названием.

Внимание: кнопки взаимоисключающие, например, Вы будете видеть кнопку В радиусе 100 км, если сейчас у Вас включен режим «Только выбранный город» и наоборот

После заполнения полей «Получатель» переходим к заполнению данных по «Списку товаровов». При обычной доставке нажмите кнопку  и переходите на шаг Подтверждение.

Список товаров

Данные используется при отправке заказов из интернет-магазинов.

  • № отправления — введите номер отправления
  • Доп. сбор за доставку с получателя — укажите сумму доп. сбора
  • № акта/ТТН — укажите номер акта или транспортной накладной
  • Истинный продавец — укажите наименование истинного продавца
  • Ставка/Сумма НДС за доп.сбор с получателя — выберите ставку НДС из выпадающего списка и поле «Сумма НДС за доп.сбор с получателя» заполнится автоматически

В списке товаров укажите характеристики товаров по каждому наименованию. Валюта стоимости товара отображается в зависимости от страны города-получателя.

Если не хватает полей для ввода новых товаров, то нажмите на кнопку Добавить или на кнопку Копировать. Удалить нежелательные или пустые места из списка можно с помощью кнопки Удалить.

Подтверждение

Перед подтверждением внимательно проверьте все введенные данные. Если необходимо их отредактировать, то переместитесь на тот пункт, который желаете изменить.

При оформлении обычной доставки таблица «Список товаров» и введенные на этом шаге данные будут отсутствовать.

Если все данные верны и не нуждаются в изменении, то после нажатия кнопки Создать заказ, будет создана накладная с присвоенным ей номером.
