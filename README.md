# Исходный сайт с очищенными подключениями

Откройте index.html. Восстановлены исходная вёрстка, цвета, калькулятор, четыре прежних видео, слайдеры, ссылки на анкету и опрос. Оригинальные архивные материалы сохранены отдельно.

Удалены служебные подключения WordPress, WooCommerce, jQuery Migrate, emoji, oEmbed, Mailchimp, Метрика и amoCRM. Удалены служебные страницы встраивания; ссылки на сами материалы сохранены. В исходных HTML, CSS и JS нет ссылок на каталоги WordPress или его обработчики.

Сохранены необходимые для исходного интерфейса jQuery, Slick и Lity. Главная страница использует три CSS и пять JS. Опрос подключает собственные стили и небольшой локальный обработчик переходов вместо плагина. Стили и изображения главной не заменялись.

Калькулятор оставлен на исходном месте. Работают поля и добавление/удаление грузовых мест; исправлены повторяющиеся идентификаторы полей. Расчёт стоимости и список городов требуют серверного API. Старый серверный адрес при проверке 13.10.2026 вернул HTTP 404; серверного кода в Wayback-копии нет. До подключения API калькулятор показывает сообщение о недоступности расчёта, а не вымышленные тарифы. Для подключения укажите адрес в переменной deliveryApi в assets/calculator.js. Контракт: POST action=find_city, q → {geonames:[{name,id}]}; POST action=sdek_calc с полями формы → {success:true,data:{тип:{тариф:{status:true,result:{title,price,deliveryPeriodMin,deliveryPeriodMax}}}}}. API должен поддерживать запросы с домена сайта. Секреты СДЭК должны оставаться на сервере.

Ссылки и превью видео возвращены к исходным. Проверено открытие и закрытие окна проигрывателя; наличие и возможность воспроизведения старых роликов зависят от YouTube. Ссылка не означает, что видео сохранено локально.

Опрос сохраняет исходные вопросы и локальные переходы. Отправка заявок и обработка ответов без сервера недоступны; локальный обработчик сообщает об этом и не показывает ложное подтверждение отправки. Остальные ограничения архивной копии сохраняются, включая возможные отсутствующие ресурсы дополнительных страниц.
